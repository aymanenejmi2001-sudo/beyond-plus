## 1. Bing Places for Business

- **URL** : https://www.bing.com/forbusiness (nouvelle interface Microsoft 2026, gestion des fiches déplacée ici)
- **Type** : fiche entreprise sur Bing et Bing Maps. Bing alimente aussi Copilot et une partie de la recherche de ChatGPT : c'est la fiche qui compte le plus pour être cité par les IA.
- **Pertinence** : les requêtes « sneakers Maroc » passent aussi par Bing et les assistants IA ; une fiche vérifiée avec le site renforce l'entité BEYOND PLUS.
- **Valeur** : forte.
- **Méthode** : se connecter avec un compte Microsoft, « Ajouter une entreprise » (ou import depuis Google Business Profile si la fiche Google existe déjà : plus rapide). Catégorie « Magasin de chaussures », adresse masquée si Microsoft le propose (vente en ligne), zone : Maroc. Réserve : Microsoft précise que certaines fonctions ne sont pas disponibles dans tous les pays ; si le Maroc n'est pas proposé, le noter dans A-ENVOYER.
- **Champs** : NAP ci-dessus + description commune.

## 2. Charika.ma

- **URL** : https://www.charika.ma/ (bouton « Ajouter mon entreprise » en page d'accueil)
- **Type** : premier site B2B d'information sur les entreprises marocaines (Inforisk), près d'un million de sociétés, très bien positionné sur Google.
- **Pertinence** : fiche d'identité de l'entreprise qui rassure les clients qui cherchent « BEYOND PLUS » avant de commander (preuve d'existence). 500 entreprises s'y ajoutent chaque mois selon le site.
- **Valeur** : forte (confiance et entité), lien vers le site selon ce que la fiche affiche.
- **Méthode** : « Ajouter mon entreprise », gratuit. Réserve : Charika s'appuie sur les données légales (RC, ICE) ; si BEYOND PLUS n'a pas encore d'identifiant légal, ne pas remplir et le signaler.
- **Message (champ « présentation »)** : description commune.

## 3. Kompass Maroc

- **URL** : https://www.kompass.com/ (portail Maroc : kompass.ma)
- **Type** : annuaire B2B international, le plus ancien annuaire du Maroc ; inscription de base annoncée gratuite.
- **Pertinence** : audience surtout professionnelle, moins client final ; intérêt : citation NAP sur un domaine très ancien et lien vers le site sur la fiche.
- **Valeur** : moyenne.
- **Méthode** : fiche de base gratuite (refuser les offres « Booster » payantes). Activité : commerce de détail de chaussures, vente en ligne.
- **Champs** : NAP + description commune.

## 4. Yalaho.ma

- **URL** : https://yalaho.ma/annuaire-maroc/
- **Type** : annuaire professionnel marocain avec expériences notées (plus de 100 000 adresses, 300 catégories, 150 villes).
- **Pertinence** : annuaire grand public, avec avis clients ; les vraies clientes pourront y laisser leur note (jamais de faux avis).
- **Valeur** : moyenne. Le site bloque les robots (403) : l'affichage du lien vers le site n'a pas pu être vérifié par l'agent, à contrôler après inscription.
- **Méthode** : inscription gratuite de l'établissement, catégorie chaussures ou mode.
- **Champs** : NAP + description commune.

## 5. Annuaire Gratuit du Maroc

- **URL** : https://www.annuaire-gratuit.ma/ (dépôt : https://www.annuaire-gratuit.ma/mon-compte/deposer-annonce.html)
- **Type** : annuaire professionnel marocain actif (articles datés de septembre 2026).
- **Pertinence** : citation NAP de plus ; pas de catégorie mode visible et pas de lien vers le site affiché sur les fiches vues. À faire seulement s'il reste du temps.
- **Valeur** : moyenne (citation), faible pour le lien.
- **Méthode** : créer un compte, « Déposer une annonce », choisir la catégorie commerce la plus proche, ajouter l'adresse du site dans la description si aucun champ n'existe.
